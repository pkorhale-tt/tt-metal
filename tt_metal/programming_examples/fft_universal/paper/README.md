# HPEC 2026 paper kit — `fft_universal`

Everything you need to (a) reproduce the numbers and (b) ship the paper.

## What's here

| File | Purpose |
|------|---------|
| `run_paper_sweep.sh` | Builds the binaries and runs the full N sweep + Brown N=16384 replica on a Wormhole box. |
| `plot_universal.py` | Reads the CSV emitted by the sweep and produces the four paper figures (PDF + PNG). |
| `00_abstract.md` … `07_conclusion.md` | First-draft paper sections in Markdown, easy to port to IEEE LaTeX. |
| `references.bib` | BibTeX entries for cited prior work. |
| `latex/main.tex` | IEEEtran skeleton that `\input`s the sections. |

## End-to-end paper workflow

```bash
# On the Wormhole machine (Linux + n300):
cd $TT_METAL_HOME
bash tt_metal/programming_examples/fft_universal/paper/run_paper_sweep.sh

# Locally (or on the same machine):
python tt_metal/programming_examples/fft_universal/paper/plot_universal.py \
    --csv paper_results/universal_sweep.csv \
    --out paper_results/figs/

# Build the LaTeX:
cd tt_metal/programming_examples/fft_universal/paper/latex
make
```

## Key claims (what makes this HPEC-worthy)

1. **Algorithmic coverage** — first published FFT on Tenstorrent that handles
   arbitrary N ≥ 2 (not just power-of-two), via a planner–composer that
   selects between four device paths.
2. **Tile efficiency win** — a packed direct-DFT kernel that drives small-N
   throughput from <3 % tile occupancy (radix-2 padding) to 6–100 %.
3. **Honest end-to-end numbers** — wall-clock latency over a 6-decade N
   sweep with a host/device breakdown column. Disclosed planner-composer
   pattern matches FFTW's and cuFFT's accepted definition of "library
   FFT" — see §4.3.
4. **Reproducibility** — every number in the paper is generated by a
   single shell script + python plotter. No hand-curated tables.
