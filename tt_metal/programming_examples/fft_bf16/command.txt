================================================================================
  tt-metal FFT (bf16) — all commands in one place
  (run from the tt-metal repo root)

This is the bfloat16 twin of tt_metal/programming_examples/fft/.
The two folders are independent; you can use either or both side-by-side.

API namespace : fft_example_bf16
Header to incl: tt_metal/programming_examples/fft_bf16/fft_host.cpp

5.  COMPARE bf16 tt-metal FFT  vs.  torch.fft.fft
--------------------------------------------------------------------------------

# Default: N=1024, seed=42, threshold 2e-1

# Specify N
python tt_metal/programming_examples/fft_bf16/compare_with_torch.py --N 4096
python tt_metal/programming_examples/fft_bf16/compare_with_torch.py --N 65536

# Change RNG seed

# Tighten/loosen threshold (bf16's noise floor is around 5e-2..2e-1)
python tt_metal/programming_examples/fft_bf16/compare_with_torch.py --N 1024 --tol 5e-2

# Keep temp .txt files
python tt_metal/programming_examples/fft_bf16/compare_with_torch.py --N 256 --keep

# Custom binary path
python tt_metal/programming_examples/fft_bf16/compare_with_torch.py \
    --N 4096 \
    --bin ./build/programming_examples/fft_bf16/metal_example_fft_bf16_vs_torch

--------------------------------------------------------------------------------
8.  DIFF vs THE FP32 VERSION  (tt_metal/programming_examples/fft/)
--------------------------------------------------------------------------------

The two folders are intentionally identical in structure. Concrete deltas:

  * tile size:   4096 B  ->  2048 B
  * DataFormat:  Float32 ->  Float16_b
  * pack/unpack: float   ->  bf16  (round-to-nearest-even)
  * test rel-err threshold: 2e-3  ->  5e-2..2.5e-1 (depending on N)
  * python --tol default:    2e-3 ->  2e-1
  * binary names: metal_example_fft_*  ->  metal_example_fft_bf16_*

Per-stage math is still fp32 (UnpackToDestFp32 + fp32_dest_acc_en); only
the storage between stages is bf16.
