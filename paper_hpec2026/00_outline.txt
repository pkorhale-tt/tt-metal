KEY CLAIMS (one sentence each — must be supported by data)
--------------------------------------------------------------------------------

C1. First unified 1-D FFT covering ALL N on Tenstorrent hardware,
    exposing the same API surface as cuFFT (single call, any dtype).

C2. L1-safe kernel composition via rebank_rm / rebank_rm_merge eliminates
    static circular-buffer overflows that blocked prior Bluestein and
    three-pass implementations for large N (>1 M).

C3. Peak throughput: 3.62 GFLOPs/s fp32, 3.44 GFLOPs/s bf16 at N=1,048,576.

C4. Energy efficiency: up to 46.9× lower energy than 24-core Xeon Platinum
    (N=16 M, bf16) using measured power (WH: 42 W, CPU: 353 W).

C5. Wall-clock crossover at N≈131 K (fp32) and N≈1 M (bf16): WH is faster
    than a 24-core server CPU at these sizes.
